Make scattered enterprise data behave like one system.

DataSong connects to the databases, warehouses, data lakes and object stores an organization already has, understands what data is available across them, and lets people discover and combine that data by asking for what they need in plain English.

The problem

Large organizations often have thousands of tables and data views spread across many different systems.

Finding the right data, understanding how datasets relate, moving data between systems and maintaining ETL pipelines becomes a significant engineering problem in itself.

DataSong is intended to reduce that work without requiring the organization to first move everything into a new central data store.

What DataSong does

DataSong connects to existing SQL and NoSQL databases, warehouses, Delta lakes, S3 and other enterprise sources. It uses AI to build a semantic understanding of the available data and exposes that knowledge conversationally.

A user can describe a new dataset or data view in English. DataSong identifies the relevant sources, determines how they can be joined, creates a governed logical view and executes the query across those systems using distributed SQL.

Request: Give me customers in India who purchased in the last 12 months, their latest support interaction and lifetime revenue.

DataSong: Customer data is in PostgreSQL, transactions are in the warehouse and support events are in S3. DataSong creates a federated view across the three sources and exposes the result as a usable dataset.

How it works

  • Connect to the organization's existing data systems.
  • Understand schemas, metadata, relationships and meaning.
  • Ask for the data needed in plain English.
  • Plan a governed federated query across the relevant sources.
  • Execute the plan using a horizontally scalable distributed SQL engine.
  • Materialize snapshots only when performance, cost or repeated use makes copying worthwhile.

Data stays governed

DataSong controls who can discover and access data, who can create views and pipelines, and which underlying sources each person or application is permitted to use.

The goal is to make enterprise data easier to use without weakening the controls around it.

Built with real organizations

DataSong is being developed in pilot mode with a small number of businesses that already have this problem. The first deployments will be built around their actual data systems and real analytics or machine-learning use cases.

Early collaborators get the resulting DataSong deployment, direct support and an extended free licence. In return, their real environment helps shape the product.
